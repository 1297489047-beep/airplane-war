# 飞机大战 ✈️

一个纯 HTML + Canvas 实现的网页飞机大战小游戏，无需任何依赖，双击 `index.html` 即可游玩。

## 玩法

- **移动**：方向键 / `WASD`，或直接用鼠标 / 触屏拖动
- **射击**：自动开火
- **暂停**：`P`
- **音效**：`M` 开关

## 游戏内容

- 三种普通敌机（小型 / 中型 / 大型），每 1000 分左右出现一次 **Boss**
- 三种道具：
  - `P` 火力升级（最高 3 级）
  - `H` 回复生命（上限 5）
  - `B` 炸弹（清屏）
- 受击后短暂无敌，生命耗尽则游戏结束
- 最高分自动保存在浏览器本地（localStorage）

## 运行

直接用浏览器打开 `index.html` 即可，或使用任意静态服务器：

```bash
# Python 3
python -m http.server 8000
# 然后访问 http://localhost:8000
```
